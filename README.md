# Quiz Game

A single-page multiplayer quiz game prototype built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern web browser. No build step or third-party dependencies are required.

## Features

- Create or join a quiz room using a room code
- Choose a quiz category, question count, and timer
- Answer timed multiple-choice questions
- View scores, rankings, and player badges
- Use the lobby chat interface

## Current limitations

Room state and chat are simulated in browser memory. They are not shared between separate browsers or devices, so real online multiplayer requires a backend service.
